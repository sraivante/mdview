# MDVIEW Sample

Welcome to **MDVIEW** — a section-wise markdown viewer and editor.

## Features

- Section cards with per-level colors
- Five themes: Light, Dark, Sepia, Nord, Forest
- Inline editing with markdown toolbar

### Editing

Click the ✏️ icon on any section to edit its heading and body.

> Tip: use `Ctrl+S` to save the file, `Ctrl+Enter` to apply an edit.
